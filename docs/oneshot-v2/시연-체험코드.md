# 시연 체험 코드(PM d-162 가)

로그인 화면에서 「체험 코드」를 넣고 「시작」을 누르면 가입 없이 들어간다. 서버가 코드를 확인한 뒤 Supabase 익명 로그인을 하고, 그 사용자 세션으로 지난 3주치 예시 데이터를 넣는다. 처음 설정은 건너뛰고 할 일 탭이 열린다.

## 켜고 끄기
- 서버 환경 변수 `DEMO_ACCESS_CODE`(NEXT_PUBLIC_ 아님). Vercel과 `.env.local`에 넣어야 칸이 보인다. 비우거나 지우면 칸이 사라지고, 서버 행동도 거절한다(`off`).
- 비교는 대소문자와 앞뒤 공백을 무시한다(화면도 대문자로 바꿔 보낸다).
- Supabase: Authentication → Sign In / Providers → 「Allow anonymous sign-ins」. CAPTCHA를 켜면 토큰 없는 익명 로그인이 실패한다(이 앱은 CAPTCHA 토큰을 보내지 않는다).

## 알아 둘 한계
- 체험 코드는 앱 화면의 문일 뿐이다. 익명 로그인을 켜 두면 누구나 공개 키로 Supabase Auth API를 직접 불러 익명 사용자를 만들 수 있다(코드 없이). 그것을 막는 것은 Supabase의 IP당 한도(익명 기본 시간당 30)와 CAPTCHA뿐이다. 익명 사용자는 자동으로 지워지지 않는다.
- 앱 서버가 signInAnonymously를 대신 부르므로, Supabase 한도가 사람마다가 아니라 Vercel 서버 IP로 세어질 수 있다. 그러면 시연 중 여러 사람이 들어오면 시간당 30번에서 막힐 수 있다. **미확인.** 확인하는 법: 시연 배포에서 체험으로 두 번 들어간 뒤, Supabase 대시보드 → Logs → Auth에서 그 두 요청(`/signup`, 익명)의 IP를 본다. 둘이 같은 Vercel IP이고 내 기기 IP가 아니면 서버 IP로 세어진다. 그러면 시연 전에 Authentication → Rate Limits에서 익명 로그인 한도를 시연 인원보다 넉넉히 올린다.
- 틀린 코드 한도(값은 모두 **임시, 결정 필요**): 창은 10분이다. 같은 기기 쿠키에서 5번 틀리면 그 기기가 막힌다. 같은 IP에서 30번 틀리면 그 IP의 모든 기기가 막힌다. IP를 모르면(헤더 없음) IP 한도는 세지 않고 기기 한도만 쓴다. 그래서 발표장 같은 Wi-Fi에서 한 사람이 5번 틀려도, 다른 사람은 IP 한도 30번 전까지 맞는 코드로 들어간다(검토 고침).
- 이 한도는 서버 인스턴스 메모리에 센다. 인스턴스가 여럿이면 그 배수까지 시도할 수 있고, 다시 뜨면 셈이 지워진다. IP는 x-forwarded-for의 첫 값이다. Vercel은 이 헤더를 덮어쓰지만, Vercel 밖에서는 보내는 쪽이 꾸밀 수 있다.

## 시험
- 단위: `npm run test`(tests/unit/demo-*.test.ts*)
- e2e(합칠 때, `.env.local`에 DEMO_ACCESS_CODE): `npx playwright test tests/e2e/demo.spec.ts`. 값이 없으면 「DEMO_ACCESS_CODE 없음」으로 실패한다.
- RLS(합칠 때): `npm run test:rls` 안의 tests/integration/demo-anon-rls.test.ts. 익명 로그인이 꺼져 있으면 「익명 로그인 꺼짐」으로 실패한다.

## 발표 뒤 할 일
1. Supabase에서 익명 로그인을 끈다. 계속 열어 둘 거면 CAPTCHA를 켠다(그때는 앱이 토큰을 보내도록 고쳐야 한다).
2. Vercel에서 `DEMO_ACCESS_CODE`를 지운다(칸이 사라진다).
3. 체험 사용자 정리 — SQL 편집기(postgres)에서. 모든 표의 user_id 외래 키가 on delete restrict라 자식 행부터 지운다. **익명 사용자 전부**가 대상이니, 먼저 `select count(*) from auth.users where is_anonymous;`로 수를 본다.

```sql
begin;
create temp table demo_users on commit drop as select id from auth.users where is_anonymous;
delete from public.todo_notes            where user_id in (select id from demo_users);
delete from public.focus_sessions        where user_id in (select id from demo_users);
delete from public.todo_offers           where user_id in (select id from demo_users);
delete from public.view_events           where user_id in (select id from demo_users);
delete from public.evening_logs          where user_id in (select id from demo_users);
delete from public.category_ratio_history where user_id in (select id from demo_users);
delete from public.category_ratios       where user_id in (select id from demo_users);
delete from public.weekly_goals          where user_id in (select id from demo_users);
delete from public.push_subscriptions    where user_id in (select id from demo_users);
delete from public.user_settings         where user_id in (select id from demo_users);
delete from public.todos                 where user_id in (select id from demo_users);
delete from public.categories            where user_id in (select id from demo_users);
delete from auth.users                   where id in (select id from demo_users);
commit;
```
