# 원샷 v2 임시값 목록

원샷 v2 빌드(2026-11-07)에서 PRD의 열린 질문·정하지 않은 값을 만나, 가장 단순하고 되돌리기 쉬운 쪽을 **임시값**으로 정한 것이다. 이 파일이 다음 고침 바퀴의 입력이다.
한 줄 꼴: **무엇 · 고른 값 · 이유 · PRD 어디**. 코드에서는 「임시」 주석이나 `lib/app-config.ts` 한 곳에서 바꾼다.

## 0 할 일 기본 기능 (G12-a)
- 기본 기능 목록 · 고치기(글·분야)·지우기(한 번 더 확인)·끝냄 표시(원래 있음)·순서(위로/아래로)·어제 못 끝낸 할 일 가져오기 · 일반 투두 앱의 당연한 기능을 가장 작게. 23 제안이 오면 바뀐다 · PRD 6절 G12-a, 7-2
- 「체크」와 「끝냄」 낱말 · 화면 글은 「끝냄」으로 맞춤(할 일 머리 「n개 중 n개 끝냄」) · 23 4-10 · PRD 7-2
- 순서 바꾸는 법 · 끌어서 옮기기 대신 「위로/아래로」 단추(끌기 없이 되는 길, WCAG 2.5.7) · PRD 10절 접근성
- 지난 날짜·앞날 보기와 적기 · 이번 바퀴에서는 넣지 않음(오늘 목록만) · 범위를 줄여 틀부터 · 기획서 7-2
- 어제 것 가져오기 · 어제 못 끝낸 것만 후보, 고른 것을 복사(어제 것은 그대로 둠), 앱이 알아서 넘기지 않음 · 기획서 7-2 「넘길지는 사용자가 고른다」
- 할 일 지우기 · 지우면 그 할 일의 작업 기록도 함께 지워짐(DB on delete cascade) · 가장 단순 · PRD 7-2
- 할 일 수정 권한 · todos update 권한을 done에서 done·text_encrypted·category_id·position으로 넓힘(DB). 기존 RLS 통합 시험 두 곳(`tests/integration/rls.test.ts`, `categories-rls.test.ts`)이 「done만」을 단언해 새 계약으로 바꿨고 **DB가 없어 돌려 보지 못함** · PRD 7-2 열린 것(22 4-5)
- 순서 저장 · todos.position(null 허용). 읽을 때 created_at 순 쿼리는 그대로 두고 서버가 position으로 안정 정렬 · 기존 시험 단언을 지키려고 · PRD 6절
- 할 일 글 상한 · 200자 그대로(기존 값) · PRD 7-2

## 0-1 작업 기록 (I1, G13-a)
- 작업 기록 단위 · 할 일 하나에 여러 개, 기록한 두노 하루를 붙임. 수정은 없고 지우고 다시 쓰기 · 단순함 · PRD 7-2
- 작업 기록 글자 수 · 2000자, 개수 상한 사용자당 20000(DB 트리거) · 남용 방지 보수값 · PRD 7-2
- 작업 기록 암호화 · 할 일 글과 같은 키·같은 형식, AAD 용도 `todo_note` · D-117과 같은 원칙 · PRD 7-9
- 작업 기록 AI 전송 동의 · 이번 틀에는 AI가 없어 동의 화면도 넣지 않음 · PRD 8절 · AI 자리: 「작업 기록을 AI에 보내는 동의」가 생길 곳은 처음 설정 끝(7-1)과 내 정보
- 분야 페이지 읽기량 · 그 분야 할 일 최근 500개까지, 날짜 최근이 위 · 임시 상한 · PRD 7-4

## ① 처음 설정 (7-1)
- 처음 설정 모양 · 네 단계(목표 → 분야 → 비율 → 알림), 단계마다 제목으로 포커스. 목표는 건너뛸 수 있고 분야·비율은 반드시 · 비율은 반드시 정한다(G4-2 가), 목표는 AI 자리 ①의 재료일 뿐이라 비워도 막지 않음 · PRD 7-1
- 비율 입력 모양 · 원형 다이얼 대신 분야마다 −/+ 5% 단추와 「고르게 나누기」 · 끌지 않고도 넣는 길이 있어야 함(WCAG 2.5.7, 23 5-5 보기 셋째) · PRD 7-1, 7-3
- 비율 합계 · 100이 아니어도 저장(합으로 나눠 읽음), 하나 이상은 0%보다 커야 함. 합계를 숫자로 보임 · 흐릿한 출발점이라 막지 않음 · PRD 7-1
- 처음 정한 비율에 기타를 넣을지 · 넣지 않음(기타는 부족한 분야로도 잡지 않음) · 가장 단순 · PRD 11절 열림
- 처음 비율 시작값 · 고른 분야를 5% 단위로 고르게 나눈 값(3개면 35·35·30) · 입력 시작을 쉽게 · PRD 7-1
- 목표 글 · 100자, 공백 정리, 암호화(AAD 용도 goal_text) · 할 일 글과 같은 원칙 · PRD 7-1, 7-9
- v8 「사용자가 정한 목표」의 뜻 · 처음 정한 비율(상태보기 부족 기준)과 이번 주 목표(건넬 분야)를 둘 다 저장하고, 목표 글은 저장만 함 · 22 2-2, PRD 7-1 열림
- 분야 예시 칩 · 어학·포트폴리오·CS 공부·자격증(lib/app-config.ts 한 곳). 마감 있는 일 없음 · D-132, PRD 5절 원칙 5
- 설정을 못 읽었을 때 · 처음 설정을 강요하지 않고 앱을 보여 줌 · 읽기 오류로 사용자를 막지 않으려고 · PRD 10절
- 이미 쓰던 사용자 · 설정 행이 없으면 처음 설정이 한 번 뜸. 이미 있는 분야는 처음부터 골라져 있음 · 같은 흐름으로 가장 단순
- 알림 허락 · 처음 설정 끝에서 묻고, 허락하면 둘 다 켜진 채 시작. 「나중에」는 꺼진 채 시작 · D-102⑤, 기획서 7-9
- 개인정보·AI 동의 화면 · 이번 틀에는 넣지 않음(AI 없음, 혼자 쓰는 판) · PRD 8절 · AI 자리: 「작업 기록 AI 동의」「개인정보 안내」는 넓히기 전에 처음 설정 끝에 한 단계로 더할 자리
- AI 자리 ① 분야 초안 · 만들지 않음. 분야는 예시 칩과 직접 입력으로만 · PRD 6절 넣지 않는 것 · AI 자리: 처음 설정 2단계(분야) 목표 글 아래
