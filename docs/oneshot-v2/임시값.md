# 원샷 v2 임시값 목록

원샷 v2 빌드(2026-11-07)에서 PRD의 열린 질문·정하지 않은 값을 만나, 가장 단순하고 되돌리기 쉬운 쪽을 **임시값**으로 정한 것이다. 이 파일이 다음 고침 바퀴의 입력이다.
한 줄 꼴: **무엇 · 고른 값 · 이유 · PRD 어디**. 코드에서는 「임시」 주석이나 `lib/app-config.ts` 한 곳에서 바꾼다.

- 비율 입력 모양 · 원형 다이얼 대신 분야마다 −/+ 5% 단추와 「고르게 나누기」 · 끌지 않고도 넣는 길이 있어야 함(WCAG 2.5.7, 23 5-5 보기 셋째) · PRD 7-1, 7-3
- 비율 합계 · 100이 아니어도 저장(합으로 나눠 읽음), 하나 이상은 0%보다 커야 함. 합계를 숫자로 보임 · 흐릿한 출발점이라 막지 않음 · PRD 7-1
- 처음 정한 비율에 기타를 넣을지 · 넣지 않음(기타는 부족한 분야로도 잡지 않음) · 가장 단순 · PRD 11절 열림
- 처음 비율 시작값 · 고른 분야를 5% 단위로 고르게 나눈 값(3개면 35·35·30) · 입력 시작을 쉽게 · PRD 7-1
- 목표 글 · 100자, 공백 정리, 암호화(AAD 용도 goal_text) · 할 일 글과 같은 원칙 · PRD 7-1, 7-9

- 분야 예시 칩 · 어학·포트폴리오·CS 공부·자격증(lib/app-config.ts 한 곳). 마감 있는 일 없음 · D-132, PRD 5절 원칙 5

- 이미 쓰던 사용자 · 설정 행이 없으면 처음 설정이 한 번 뜸. 이미 있는 분야는 처음부터 골라져 있음 · 같은 흐름으로 가장 단순
